# Data Sheet: Mind2Web

Mind2Web выбран как возможный набор для **оценки** подсказок «Умного коллеги» при работе с веб-интерфейсами. Авторы Qwen2.5-7B-Instruct не указывают Mind2Web как обучающий набор этой модели; считать его частью её обучения нельзя.

## Общая информация

**Название датасета:** Mind2Web.  
**Источник:** [страница набора на Hugging Face](https://huggingface.co/datasets/osunlp/Mind2Web) и [репозиторий авторов](https://github.com/OSU-NLP-Group/Mind2Web).  
**Назначение:** разработка и оценка агентов, которые выполняют описанные обычным языком задачи на веб-сайтах.  

## Состав данных

**Объём:** 2 350 задач с 137 сайтов из 31 предметной области. Обучающая часть содержит 1 009 задач; тестовые части — 252 задачи Cross Task, 177 Cross Website и 912 Cross Domain. На странице Hugging Face в просмотрщике доступна обучающая часть, а тестовые части авторы распространяют отдельно.  
**Тип данных:** англоязычные описания задач, последовательности действий и текстовые снимки HTML-страниц.  
**Основные поля / признаки:** `annotation_id`, `website`, `domain`, `subdomain`, `confirmed_task`, `action_reprs`, `actions`. Для шага действия доступны тип операции (`CLICK`, `TYPE` или `SELECT`), исходный и очищенный HTML, а также кандидаты элементов страницы.

## Получение данных

Авторы отобрали реальные веб-сайты и собрали описания задач и последовательности действий с помощью аннотаторов. Для каждого шага сохранены сведения об интерфейсе до действия. Тестовые данные распространяются отдельно, чтобы уменьшить риск попадания ответов в обучающие корпуса.

## Предобработка

В опубликованной структуре есть `raw_html` и `cleaned_html`; после обработки HTML авторы выделяют положительные и отрицательные элементы-кандидаты. Некоторые исходно размеченные элементы могут отсутствовать в очищенной версии, поэтому список `pos_candidates` бывает пустым. Для этого проекта дополнительная предобработка датасета не выполнялась.

## Ограничения

- Задачи и доступные языковые метки — английские. По этому набору нельзя напрямую судить о качестве русскоязычных подсказок.
- Набор охватывает 137 сайтов, но не все типы интерфейсов и состояния, которые встретятся в проекте. Перенос результатов на новые веб-сервисы требует отдельной проверки.
- Снимки страниц фиксируют состояние на момент сбора. Изменения интерфейсов со временем могут сделать некоторые действия неактуальными.
- Публичный обучающий набор и отдельные тестовые части нужно разделять при оценке, чтобы избежать утечки тестовых ответов.

## Использование в проекте

Mind2Web можно использовать для проверки, выбирает ли модель следующий шаг и нужный элемент по описанию задачи и состоянию страницы. Для «Умного коллеги» это соответствует созданию сценария и запросу следующей подсказки через [API проекта](../api/index.md). Перед практическим применением понадобятся собственные русскоязычные примеры и проверка на актуальных интерфейсах.
