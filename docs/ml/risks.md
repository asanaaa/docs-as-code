# Риски и ограничения

## Потенциальный bias

### Языковое смещение

**Риск:** Mind2Web содержит англоязычные задачи. Существует потенциальный риск, что оценка на нём не покажет ошибки в русскоязычном интерфейсе.  
**Возможное последствие:** ассистент может хуже понимать русские названия элементов и формулировки задач.  
**Что можно сделать:** собрать отдельную русскоязычную тестовую выборку и сравнить успешность выбора следующего шага по языкам.

### Смещение по типам сайтов

**Риск:** Mind2Web охватывает конкретные сайты и области; доступной информации недостаточно, чтобы считать их представительными для всех сервисов «Умного коллеги».  
**Возможное последствие:** хорошая оценка на известных сайтах может скрыть ошибки на корпоративных системах и новых интерфейсах.  
**Что можно сделать:** проверять результат отдельно на новых сайтах и разных типах задач, а при затруднении предлагать пользователю ручной путь.

## Этические риски

### Данные страницы и пользователя

**Риск:** описание страницы, передаваемое модели, может содержать имена, адреса, сообщения или другие личные сведения.  
**Последствие:** эти сведения могут оказаться доступны системе обработки сверх необходимого объёма.  
**Способ снижения риска:** передавать только элементы, нужные для текущей подсказки; скрывать личные значения полей; ограничивать хранение и доступ к запросам.

### Неверная подсказка и чрезмерное доверие

**Риск:** модель может уверенно предложить неправильный шаг или устаревший элемент интерфейса.  
**Последствие:** пользователь может совершить ошибку, особенно при платежах или изменении настроек доступа.  
**Способ снижения риска:** проверять наличие целевого элемента в актуальном состоянии страницы, обозначать подсказку как предложение ИИ и оставлять подтверждение значимых действий за человеком.
