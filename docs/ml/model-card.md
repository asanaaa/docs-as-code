# Model Card: Qwen2.5-7B-Instruct

Эта модель рассматривается как возможный компонент проекта «Умный коллега». Модель не запускалась и её качество в проекте пока не измерялось.

## Общая информация

**Название модели:** Qwen2.5-7B-Instruct.  
**Источник:** [карточка модели на Hugging Face](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct).  
**Автор / организация:** Qwen Team, Alibaba Cloud.  
**Задача модели:** генерация текста по инструкциям; модель может формировать объяснения и структурированные ответы.  
**Язык:** многоязычная модель; авторы перечисляют среди поддерживаемых языков русский и английский.  
**Лицензия:** Apache 2.0.  
**Данные обучения:** авторы описывают крупный набор данных для семейства Qwen2.5, но точный состав обучающих данных именно этой версии в карточке не указан.

## Использование в проекте

В проекте «Умный коллега» модель могла бы получать задачу пользователя и текстовое описание текущей страницы: адрес, заголовок и доступные элементы. Она формировала бы краткую подсказку о следующем действии и идентификатор элемента, на который следует обратить внимание. Это соответствует операциям [`POST /guides` и `POST /guides/{guideId}/next`](../api/index.md). Приложение должно проверять, что предложенный элемент действительно есть в текущем интерфейсе, прежде чем показывать подсказку.

## Входные данные

Текстовая инструкция, составленная из задачи пользователя и описания состояния веб-страницы. В API проекта эти сведения передаются в полях `task` и `page`. Модель получает текст, поэтому визуальные свойства страницы сами по себе ей недоступны.

## Выходные данные

Сгенерированный текст. В проекте его предполагается преобразовывать в объект подсказки `Hint`: текст шага, номер шага и, если найден подходящий элемент, `targetElementId`. Формат объекта обеспечивает приложение; сама модель не гарантирует корректность идентификатора или JSON без проверки.

Числовые метрики для **Qwen2.5-7B-Instruct** в её карточке не указаны: раздел Evaluation & Performance отсылает к [публикации Qwen Team](https://qwenlm.github.io/blog/qwen2.5/). ## Ограничения

1. **Указано авторами:** стандартная конфигурация поддерживает контекст до 32 768 токенов. Для более длинного контекста требуется отдельная настройка YaRN; это важно для больших страниц.
2. **Потенциальное ограничение для нашего проекта:** текстовое представление страницы может не передать расположение, иконки и другие визуальные признаки; подсказка для таких элементов может быть неверной. Это нужно проверить на реальных интерфейсах.
3. **Потенциальное ограничение для нашего проекта:** модель может предложить элемент, которого уже нет после обновления страницы. Нужны проверка `targetElementId` и повторный анализ состояния.
4. **Потенциальное ограничение для нашего проекта:** поддержка русского языка не доказывает качество именно русскоязычных инструкций по интерфейсу. Требуется отдельная оценка на таких задачах.

## Не рекомендуется использовать

Модель не следует использовать как единственный механизм для автоматического подтверждения платежей, изменения прав доступа и других действий с серьёзными последствиями. Пользователь должен видеть предлагаемый шаг и самостоятельно подтверждать действие. Также не следует считать сгенерированную подсказку доказательством того, что задача уже выполнена.
