# Умный коллега

Автономный ИИ-ассистент, который изучает веб-сервис, анализирует его интерфейс и действия пользователя, а также в реальном времени подсказывает, как выполнять необходимые задачи. Ассистент помогает быстрее освоить незнакомый сервис, разобраться в его функциях и избежать ошибок при работе.

**Основные пользователи:**

- пользователь веб-сервиса;
- новый сотрудник, осваивающий рабочие инструменты;
- сотрудник, которому необходима помощь при выполнении задач.

**Основные функции:**

- изучение структуры и функциональных возможностей веб-сервиса;
- анализ текущего состояния интерфейса и действий пользователя;
- предоставление контекстных подсказок в реальном времени;
- пошаговое сопровождение пользователя при выполнении задач;
- объяснение назначения элементов интерфейса и доступных действий.


**Комплект документации:**

- Описание проекта — предназначено для всех участников проекта, содержит общую информацию о назначении, целях и возможностях системы.
- Техническое задание и требования — предназначено для разработчиков и заказчика, описывает функциональные и нефункциональные требования к ИИ-ассистенту.
- Архитектура системы — предназначена для разработчиков, описывает структуру системы, взаимодействие её компонентов и принципы работы.
- Документация ИИ-модели — предназначена для ML-разработчиков, описывает используемые модели, принципы анализа интерфейса, обработки действий пользователя и генерации подсказок.
- Руководство пользователя — предназначено для конечных пользователей, объясняет, как подключить ассистента, пользоваться подсказками и выполнять задачи с его помощью.
