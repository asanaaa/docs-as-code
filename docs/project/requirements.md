# User Stories

### US-01. Анализ веб-сервиса

Как пользователь веб-сервиса,
я хочу, чтобы ИИ-ассистент автоматически изучал интерфейс и его доступные функции,
чтобы быстрее разбираться в незнакомом сервисе.

**Критерии приёмки:**

- ассистент может анализировать структуру открытой страницы;
- система определяет основные элементы интерфейса и их назначение;
- результаты анализа используются для формирования подсказок.

### US-02. Получение контекстных подсказок

Как пользователь веб-сервиса,
я хочу получать подсказки от ИИ-ассистента в реальном времени,
чтобы понимать, какие действия необходимо выполнить на текущем этапе.

**Критерии приёмки:**

- ассистент анализирует текущее состояние страницы;
- система отображает подсказки, соответствующие текущему интерфейсу;
- подсказки обновляются при переходе на другую страницу или изменении состояния интерфейса.

### US-03. Пошаговое выполнение задачи

Как новый пользователь веб-сервиса,
я хочу получать пошаговые инструкции по выполнению задач,
чтобы самостоятельно освоить функциональность сервиса без посторонней помощи.

**Критерии приёмки:**

- пользователь может описать задачу, которую хочет выполнить;
- ассистент формирует последовательность необходимых действий;
- после выполнения каждого шага ассистент помогает перейти к следующему.

## UC-01. Получение пошаговых подсказок при работе с веб-сервисом

**Актор**: пользователь веб-сервиса.

**Цель**: получить помощь от ИИ-ассистента при выполнении задачи в незнакомом веб-сервисе.

**Предусловие**: пользователь открыл веб-сервис, а ИИ-ассистент подключён и готов к работе.

**Основной сценарий:**

1. Пользователь открывает нужную страницу веб-сервиса.
2. ИИ-ассистент анализирует интерфейс и определяет доступные действия.
3. Пользователь описывает задачу, которую хочет выполнить.
4. Ассистент анализирует задачу и текущее состояние интерфейса.
5. Система формирует последовательность необходимых действий.
6. Ассистент отображает пользователю первую подсказку.
7. После выполнения действия система анализирует обновлённое состояние страницы и предлагает следующий шаг.

**Альтернативный сценарий:**

Если ассистент не может определить необходимые действия или проанализировать интерфейс, система сообщает пользователю о проблеме и предлагает повторить анализ.

**Результат**: пользователь получает пошаговые подсказки и может самостоятельно выполнить задачу в веб-сервисе.
