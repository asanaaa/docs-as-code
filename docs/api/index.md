# API «Умного коллеги»

API описывает, как веб-сервис может запросить у ИИ-ассистента пошаговую помощь для пользователя. Это проект документации: сервер по указанному адресу не реализован.

## Основные операции

| Метод и путь | Назначение |
| --- | --- |
| `POST /guides` | Создать сценарий по задаче и текущему состоянию страницы; получить первую подсказку. |
| `GET /guides/{guideId}` | Узнать текущий шаг и последнюю подсказку сценария. |
| `POST /guides/{guideId}/next` | Передать обновлённое состояние страницы после действия пользователя и получить следующую подсказку. |

## Спецификация

Полные схемы запросов и ответов, примеры и коды ошибок приведены в файле [openapi.yaml](openapi.yaml).
